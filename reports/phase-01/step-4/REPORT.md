## 2. Actual changes
**Endpoints**
- 99 PHASE_01 operations are served over HTTP: the 97 planned ones plus 2 new operations.
- New package `backend/platform_core/api/phase01/`, with views per area (auth, identity, org, workflow, documents, config, ops), serializers and urls.

**Authentication** (`api/session_auth.py`)
- Session cookie: HttpOnly and SameSite=Lax; Secure in staging and production.
- CSRF is enforced on login and on every unsafe request.
- A failed authentication is raised after the throttles run, so rejected requests are still rate-limited.

**Policy switch**
- `ACCESS_POLICY = RbacPolicy(...)` replaces DenyAll. Deny by default holds:
  - an action outside the catalogue gets 403;
  - an out-of-scope record gets 404.
- MFA step-up is enforced from the permission's DB flag.
- `PUBLIC_OPERATIONS` = the 3 probes + `getLoginContext` + `login`.

**HTTP conventions**
- Login rate limits per IP and per username (`ALEEKHAN_RATE_LOGIN_IP` / `_LOGIN_USER`).
- Idempotency-Key on writes:
  - an upload hashes the file digest, not the bytes;
  - one-time passwords are never stored in idempotency records.
- If-Match/ETag with row_version.
- Pagination.
- X-Request-ID is propagated to audit and outbox rows.
- Write order: the permission, then the Idempotency-Key, then If-Match. Under the row lock, the record scope is checked before the version, so an out-of-scope id never answers 412.

**Minimal new services, for operations that had none in 01.3**
- Updates of user, DRAFT role, unit and document metadata; position title and unit head.
- Audited download.
- Parameter definitions and dynamic-field drafts.
- Task notes and `due_at`.
- Approvals inbox.
- Server-generated one-time passwords.

**Bugs found by the API tests and fixed**
- `mfa.reset_factors` returned 500 when there was nothing to reset. It now always emits its outbox event.
- A DB-guard refusal in the new update services returned 500. It now returns 409 with the rule name.

**Other**
- REV-0118 fixed: the always-true assertion in `test_phase01_rework1.py`.

## 3. Contract decisions (OpenAPI 0.6.0-draft = `CONTRACT_VERSION`)
1. All planned markers are removed. Route parity covers 88 paths and 107 operations, with 0 planned.

3. New operation `stepUpMfa` (`POST /auth/mfa/step-up`), exempt from Idempotency-Key like the other credential operations (C-27).
