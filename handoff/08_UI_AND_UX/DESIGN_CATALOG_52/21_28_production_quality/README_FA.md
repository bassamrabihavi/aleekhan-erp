جستجو، فیلتر وضعیت، افزودن ردیف موقت، پنجره عملیاتی، بررسی دلیل برای عمل حساس و ناوبری آزمایشی. این تعامل‌ها فقط در حافظه مرورگر نمونه‌اند و در Refresh حذف می‌شوند.

## محدودیت و موارد باز

- اتصال به بانک اطلاعاتی عملیاتی، راهکاران، پیگیری اسناد و OPC واقعی وجود ندارد.
- اعداد و سریال‌ها نمایشی‌اند؛ حتی اگر به داده واقعی شباهت دارند نباید به‌عنوان وضعیت واقعی کارخانه استفاده شوند.
- تمام DTOها، وضعیت‌ها، ACL و قواعد UI باید با Data Dictionary مصوب و مالک فرآیند نهایی شوند.
- نمایش گرید A+/A/B/C روی صفحه، جایگزین Acceptance Criteria مشتری نیست.
- برای پایلوت واقعی، سازگاری با داده‌های Migration و کنترل مقدارها و رزرو، QC و حواله الزامی است.
