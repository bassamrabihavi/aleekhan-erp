## استفاده

فایل `index.html` را باز کنید و در نوار افقی روی شماره صفحات ۱۳ تا ۲۰ کلیک کنید. بدون نصب وابستگی به اینترنت کار می‌کند. برای بررسی Responsive، عرض پنجره را تغییر دهید؛ در موبایل منوی سمت راست با دکمه ☰ باز می‌شود.

## محتویات
- `index.html`: HTML اصلی RTL
- `assets/styles.css` و `assets/app.js`: UI مشترک، ناوبری، جدول، فیلتر، پنجره نمایشی، سایدبار Hover/Pin و Drawer موبایل
- `DESIGN_CONTRACT.json`: فیلدهای اصلی هر صفحه، مالک، API و محدودیت‌ها
- `PAGE_REGISTRY.json`: نقشه ناوبری و صفحه‌ها
- `DATA_MODEL.md`: جداول منطقی، Revision، مرزهای مالکیت و تراکنش
- `API_CONTRACT.md`: قرارداد اولیه سرویس و پاسخ خطا
- `QA_TESTS.md`: موارد QA برای Codex/Claude Code
- `MIGRATION_AND_SOURCE.md`: وضعیت بررسی فایل‌ها و مرز ادعاها
- `previews/*`: تصاویر مانیتور، لپ‌تاپ، تبلت و موبایل برای هر صفحه

## مهم
- عددهای نمونه، کدهای غیررسمی و وضعیت‌ها داده زنده کارخانه نیستند.
- کد ۱۴رقمی راهکاران محصولات و تیغه‌ها در معماری پذیرفته شده؛ موتور صدور کد تیغه تا دریافت اسکریپت قدیمی تأیید نشده است.
- صِرف وجود Layer در DXF به معنی تیغه، مقر یا ناحیه لیویس تأییدشده نیست.
- عمل افزودن ردیف و Confirm داخل HTML فقط محلی است و عملیات در DB ذخیره نمی‌شود.
- تأیید نهایی پیکسل‌به‌پیکسل و پایلوت عملیاتی پس از ساخت همچنان لازم است.
