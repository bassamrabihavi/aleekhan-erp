# بسته طراحی صفحات ۳۷ تا ۴۴ — سراجی سنتی عالیخان

این بسته **نمونه طراحی UI/UX و قرارداد فنی اولیه** است؛ سیستم عملیاتی، API واقعی، راهکاران، حقوق، پایگاه داده یا سیستم تولید را تغییر نمی‌دهد.

## صفحات و مالکیت

- **37** — عملکرد کارکنان و خطوط | ماژول مالک: منابع انسانی و عملکرد
- **38** — مهارت‌ها، آموزش و درخواست تغییر حقوق | ماژول مالک: منابع انسانی
- **39** — صندوق کارها و تأییدهای سازمانی | ماژول مالک: گردش کار و همکاری سازمانی
- **40** — مدیریت اسناد فنی و نسخه‌ها | ماژول مالک: سرویس اسناد و رسانه
- **41** — مرکز استانداردسازی و کیفیت داده | ماژول مالک: حاکمیت داده / Steward تخصصی
- **42** — مدیریت پارامترها و چیدمان صفحات | ماژول مالک: مدیریت سیستم / حاکمیت پیکربندی
- **43** — مرکز ورود فایل‌های راهکاران | ماژول مالک: یکپارچه‌سازی داده‌ها
- **44** — مرکز مغایرت و تطبیق اطلاعات | ماژول مالک: یکپارچه‌سازی داده‌ها / امضای مالک واحد

## نحوه مشاهده

`index.html` را با مرورگر باز کنید؛ در برخی محیط‌ها برای مشاهده فایل‌های لوکال ممکن است سرویس HTTP محلی لازم باشد. با پارامتر `?page=41` می‌توان صفحه را مستقیم باز کرد. HTML، CSS و JS بدون CDN و بدون اتصال اینترنت کار می‌کنند.

## موارد تست‌شده

- چهار نما برای هر ۸ صفحه: دسکتاپ، لپ‌تاپ، تبلت و موبایل؛ ۳۲ Screenshot
- ناوبری صفحات، تغییر فیلتر، انتخاب تسک و مغایرت، جابه‌جایی و افزودن فیلد آزمایشی
- الزام دلیل برای اقدام‌های حساس در نمونه نمایشی
- عدم مشاهده مبلغ حقوق برای نقش نمایشی فاقد مجوز
- اسکرول جدول درون پنل، Sidebar سمت راست

## محدودیت‌ها و موارد باقی‌مانده

- داده‌های روی صفحه صرفاً **نمونه/ساختگی** هستند و نباید به عنوان داده استخراج‌شده از فایل‌های واقعی نمایش داده شوند.
- طراحی و Data Contract در مرحله Draft هستند و پیش از کدنویسی باید فیلدبه‌فیلد با کاربر تأیید شوند.
- رابط APIهای پیشنهادی هنوز قرارداد اجرایی نیست و نیاز به OpenAPI/DTO/Schema نهایی دارد.
- تست‌های فعلی Smoke UI هستند؛ تست امنیت، همزمانی، صحت پول و موجودی، Restore و Import واقعی باقی است.
- تحویل نهایی به Codex/Claude Code باید همه بسته‌ها، DB migrations، backend rules و acceptance tests را یکپارچه کند.
