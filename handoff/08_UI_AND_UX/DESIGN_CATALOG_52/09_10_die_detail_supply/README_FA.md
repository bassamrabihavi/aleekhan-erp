# صفحات ۰۹ و ۱۰ — نمونه اجرایی بصری

پروژه: سامانه یکپارچه مدیریت تولید **سراجی سنتی عالیخان**

## نحوه بازکردن

- `index.html?page=die`: صفحه ۰۹، «پرونده فنی و سوابق تیغه»؛ مالک داده فنی: **مهندسی و طراحی**.
- `index.html?page=supply`: صفحه ۱۰، «درخواست ساخت و پیگیری تأمین تیغه»؛ مالک پیگیری ساخت: **تأمین**.
- می‌توان از دکمه‌های داخل دو صفحه بین آن‌ها رفت.
- منوی سمت **راست** در دسکتاپ جمع‌شده است؛ روی آن Hover کنید تا باز شود. آیکون سنجاق آن را ثابت می‌کند. در موبایل دکمه منو، Drawer راست را باز می‌کند.

## ملاحظات داده واقعی و نمونه

- کد نمونه‌ی `05020121450110` از فایل `جدول پیگیری تیغه.xlsx` و داده استخراج‌شده قبلی استفاده می‌کند؛ کد نمونه به معنی تایید فنی، موجودی یا وضعیت واقعی آن تیغه نیست.
- شرح منبع نمونه: `تیغه چوبی koropon 4 tayi lop tableh` و محصول اولیه ۲۱۴۵ از همان ردیف گزارش‌شده.
- شکل هندسی نمایش‌داده‌شده در صفحه ۰۹ **صرفاً شماتیک** است؛ هندسه واقعی این تیغه از فایل DXF آن استخراج نشده است.
- تمامی اعداد شاخص صفحه ۱۰، درخواست‌های `REQ-DEMO`، وضعیت‌ها و تاریخ‌ها **نمونه نمایشی** هستند.
- کدهای راهکارانِ محصولات و تیغه‌ها هر دو ۱۴رقمی هستند؛ **الگوریتم کدگذاری تیغه مستقل** است و تا دریافت اسکریپت Python اصلی نباید از الگوی کد محصول حدس زده شود.
- فایل Python خواندن DXF و ثبت در «جدول پیگیری تیغه» هنوز از کاربر دریافت نشده؛ اتصال Scan خودکار و Write-back **فعلاً در این نمونه وجود ندارند**.

## تعامل‌های آزمایشی پیاده‌شده

1. تغییر صفحه بین پرونده تیغه و درخواست ساخت
2. بازکردن و بستن/سنجاق کردن Sidebar سمت راست
3. بازکردن Drawer از سمت راست روی موبایل
4. نمایش پنجره توضیح و نیاز به واردکردن دلیل قبل از ثبت نمایشی
5. فیلتر و جستجو روی درخواست‌های نمونه
6. ثبت پیگیری تأمین به‌صورت محلی داخل همان صفحه، بدون تغییر داده رسمی
7. تب‌های تاریخچه، Revision و تأییدها

**هیچ اتصال Backend، Database، File Server یا Rahkaran وجود ندارد.** کد نمونه فقط UX و تعامل فرانت‌اند را مشخص می‌کند.

## جایگاه در معماری

صفحه ۰۹ در `مهندسی > مدیریت تیغه‌ها > پرونده تیغه`؛ صفحه ۱۰ در `تأمین > سفارش ساخت ابزار > پیگیری ساخت تیغه`. انبارک صفحه جداگانه برای نسخه‌های فیزیکی، شمارش، محل و تحویل دارد و در این دو صفحه فقط اطلاعات آن نمایش/درخواست می‌شود.

## فایل‌ها

- `index.html`: نمونه HTML و CSS و JavaScript بدون وابستگی خارجی
- `die_desktop.png`، `die_laptop.png`، `die_tablet.png`، `die_mobile.png`: تصاویر صفحه ۹
- `supply_desktop.png`، `supply_laptop.png`، `supply_tablet.png`، `supply_mobile.png`: تصاویر صفحه ۱۰

- `DATA_MODEL.md`: ساختار منطقی داده و روابط

- `QA_TESTS.md`: معیارهای پذیرش و سناریوهای تست
