# ردیابی منابع و موارد قابل‌اثبات

- صفحه ۲۹ مبتنی بر ساختار مستند `Planning--.xlsm` است: `Order form`، `NOrder`، `Sorce`، `Codding`؛ پیش‌نمایش کد ۱۴رقمی فقط برای حالت نمونه جیبی/جاکارتی در این Prototype تأیید مفهومی شده است؛ سایر دسته‌ها نیازمند تبدیل کامل فرمول و Macro به Coding Rule Version هستند.
- صفحه ۳۰ بر اساس معماری تأییدشده Order Program و Forecast Consumption طراحی شده؛ اعداد نمایشی هستند.
- صفحات ۳۱ و ۳۲ براساس معماری OPC، Capacity, Shared Resource Pool و Delta-Replanning ساخته شده‌اند؛ تخصیص منابع و SWU تصویرشده محاسبه واقعی نیست.
- صفحه ۳۳ بر اساس CR/ECR/ECO و تغییر مقدار یا لغو سفارش؛ مقادیر فقط نمونه‌اند.
- صفحه ۳۴ از Costing Engine پیشنهادی، نه قیمت‌های تأییدشده راهکاران یا فاکتور واقعی، استفاده می‌کند.
- صفحه ۳۵ از KPI Dictionary و Data Freshness طراحی شده؛ بخش وصول واقعی تا اتصال داده مالی فعال/معتبر نیست.
- صفحه ۳۶ Job، Audit و Monitoring را نشان می‌دهد؛ نمونه HTML به Process یا سرور واقعی دسترسی ندارد.

**جداسازی منبع از فرض:** هیچ داده مثال، KPI، قیمت یا تاریخ تصویرشده را واقعیت جاری کارخانه تلقی نکنید. اثر یک تغییر واقعی پس از اتصال، فقط از موتور تخصصی Domain و تأیید انسانی صادر می‌شود.
