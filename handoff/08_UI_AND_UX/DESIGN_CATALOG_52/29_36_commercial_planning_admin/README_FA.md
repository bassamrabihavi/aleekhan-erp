## اجرا
`index.html` را در مرورگر باز کنید؛ `?page=29` تا `?page=36`. بدون اینترنت و بدون وابستگی خارجی اجرا می‌شود. روی موبایل، Drawer از سمت راست باز می‌شود. وقتی از حالت فایل محلی استفاده می‌کنید، برخی مرورگرها history navigation را محدود می‌کنند ولی بازکردن هر صفحه از query link معتبر است.
