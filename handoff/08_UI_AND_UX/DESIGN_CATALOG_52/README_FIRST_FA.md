# کاتالوگ اولیه ۵۲ صفحه سراجی سنتی عالیخان

**این بسته برای بازبینی UI است، نه برای کدنویسی خودکار کامل.** صفحات ۱–۲ صرفاً طرح اولیه‌اند؛ صفحات بعدی HTML تعاملی و اسناد متفاوت دارند. همه نیازمند تأیید، تست واقعی و ادغام قراردادهای API/ERD هستند.

ابتدا `index.html` را باز کنید و صفحات را یک‌به‌یک بررسی کنید.

برای ادامه: Signoff هر صفحه، بازبینی کدگذاری Planning/WH و فایل Python تیغه، یکپارچه‌سازی Schema و Event/Workflow/Permission، ساخت تست‌ها، پایلوت واقعی و کنترل Go-live.
