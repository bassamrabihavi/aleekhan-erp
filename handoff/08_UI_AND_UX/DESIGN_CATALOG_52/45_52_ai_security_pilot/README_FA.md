# سامانه مدیریت سراجی سنتی عالیخان — طرح صفحات ۴۵ تا ۵۲

این مجموعه تکمیل‌کننده **طراحی اولیه ۵۲ صفحه** است. طراحی اولیه به معنی تأیید دقیق فیلدها، جریان‌ها یا تکمیل Backend نیست.

- صفحه **45**: دستیار هوشمند سازمانی — ماژول مالک: **AI Gateway**
- صفحه **46**: مدیریت کاربران، نقش‌ها و امنیت — ماژول مالک: **مدیریت سیستم**
- صفحه **47**: داده‌های پایه و موتور قوانین — ماژول مالک: **داده‌های پایه / Admin پیکربندی**
- صفحه **48**: تابلوی زنده عملکرد سالن تولید — ماژول مالک: **تولید**
- صفحه **49**: موجودی، شمارش دوره‌ای و مرجوعی مواد — ماژول مالک: **مواد و انبار**
- صفحه **50**: عدم انطباق، CAPA و مجوز انحراف — ماژول مالک: **تضمین کیفیت QA**
- صفحه **51**: نگهداری ماشین‌ها و کالیبراسیون — ماژول مالک: **نگهداری و تعمیرات**
- صفحه **52**: مدیریت پایلوت، خطاها و انتشار نسخه — ماژول مالک: **مدیریت سیستم / دفتر پروژه**

## استفاده
`index.html` و فایل‌های `assets/` را در یک سرویس استاتیک یا مرورگر پشتیبان فایل محلی باز کنید. با `?page=50` می‌توان مستقیماً به صفحه ۵۰ رفت.

## محدودیت
اعداد و رکوردهای داخل صفحات صرفاً **نمایشی** هستند. هیچ AI، راهکاران، پایگاه داده، سامانه حقوق، ERP، برنامه زمان‌بندی، سنسور ماشین یا خط تولید به این Prototype متصل نیست.

## تحویل نهایی مورد نیاز برای Codex / Claude Code
Design System واحد، Route Registry واقعی، API OpenAPI / DTO و Migration، Rule Catalog، Permission Matrix، Event Catalog، Test Fixtures، Data Migration، Test Plan/Regression، Pilot Gate و Release/Rollback باید بعد از تأیید صفحات یکپارچه شوند.
