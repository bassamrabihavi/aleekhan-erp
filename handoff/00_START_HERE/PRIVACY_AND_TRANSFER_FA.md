# راهنمای انتقال امن بسته

**توجه: خود ZIP معمولی رمزگذاری نشده است.** `09_PRIVATE_FACTORY_SOURCES` شامل داده داخلی و ماکروهای قدیمی است. این بسته باید مانند سند محرمانه شرکت نگهداری شود.

- اگر Codex/Claude Code در محیط Cloud بدون قرارداد محرمانگی/مجوز است، فقط زیرپوشه‌های مستندات و پروتوتایپ را منتقل کن؛ منابع خصوصی را تا تصویب سیاست داده در محیط محلی نگه دار. برای اجرای Golden Tests در محیط محلیِ مجاز از source files استفاده شود.
- اگر Agent روی سیستم خصوصی مجاز کار می‌کند، بسته را در پوشه دسترسی محدود Extract کن؛ Raw Source را فقط read-only mount کن و در Git commit نکن.
- هنگام تحویل به پیمانکار/Agent، ZIP را با ابزار رمزگذاری سازمانی در کانال خصوصی منتقل کن؛ رمز را در خود ZIP یا پیام عمومی قرار نده.
- Snapshot منابع و فایل‌های جدید تولیدی هر کدام باید SHA-256 داشته باشند؛ مانع بازنویسی فایل اصلی شو.
