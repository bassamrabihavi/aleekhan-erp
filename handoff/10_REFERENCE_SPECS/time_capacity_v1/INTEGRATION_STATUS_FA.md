# ادغام در برنامه فازبندی عالیخان

وضعیت تحویل: بسته کامل **SPECIFICATION ONLY** برای موتور زمان‌سنجی/ظرفیت‌سنجی چهار خانواده تهیه شد. هیچ برنامه کاربردی، API قابل اجرا، Migration واقعی، زمان استاندارد مصنوعی یا پایگاه‌داده عملیاتی ساخته نشده است.

این بسته بخشی از فازهای اصلی «مهندسی/OPC»، «برنامه‌ریزی/ظرفیت»، «تولید/ترمینال»، «منابع انسانی/صلاحیت»، «تعمیرات» و «QA» است؛ در هنگام توسعه باید به Repository یکپارچه متصل شود، نه اینکه یک نرم‌افزار مجزا ایجاد کند.

**شروع مجاز توسعه:** مدل داده و ثبت خام با Guardrails؛ **شروع غیرمجاز:** Commit ظرفیت یا KPI واقعی بدون تأیید Standard/SWU/Resource Calendar.

## وضعیت وابستگی‌ها
- `Ready for development`: قرارداد خام Observation، مدل Resource/Shift/Skill، ساختار نسخه و Audit، قالب UI و تست‌ها.
- `Blocked for production activation`: زمان و تعداد نمونه واقعی، تأیید مسیر کفش، ضریب allowance/rating، سیاست SWU، شناسنامه ماشین/شیفت/Skill و تأیید کاربرد معیارهای فردی.

خروجی‌های قابل ارائه به Codex: `ENGINE_CONTRACT.json`، مستندات فارسی، CSV خام، سناریوهای پذیرش، ماتریس امنیت و الگوی گزارش هر Slice.
