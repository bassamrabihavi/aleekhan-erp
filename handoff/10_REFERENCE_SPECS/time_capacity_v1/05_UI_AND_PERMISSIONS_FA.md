# ۵. طرح UI، نقش‌ها و اتصال به صفحات ۵۲گانه

قانون: **صفحات فعلی افزایش نمی‌یابند**؛ زیرصفحه یا Tabهای تخصصی در Owner Module افزوده می‌شوند. طراحی‌های قبلی ۱۰۰٪ پیش‌نویس‌اند، نه مصوب نهایی.

| صفحه موجود | Tab / Widget جدید | مالک و حق ویرایش |
|---|---|---|
| ۱۶ — OPC | زمان مصوب (نفر/ماشین/Setup/Wait)، منبع استاندارد، وضعیت مطالعه، Scope/Revision، شروع مطالعه، انتشار | مهندسی |
| ۳۲ — شبیه‌ساز ظرفیت | شیفت، ماشین مشترک، Skill، تقاضای نفر-دقیقه/ماشین-دقیقه، Bottleneck، زمان موعد، What-if، معیار اطمینان | برنامه‌ریزی |
| ۳۱ — برنامه تفصیلی | Gantt با عملیات درون بچ، آماده‌به‌کار و Blockها، برنامه مصوب | برنامه‌ریزی |
| ۲۲ — مدیریت خطوط | بار هر ایستگاه، ظرفیت مؤثر، صف، ماشین مشترک، افت/افزایش ظرفیت | تولید / خواندن برنامه‌ریزی |

| ۳۶ — Health Center | Jobهای Solver، duration، cancellation، unsafe retry، lock/queue status | ادمین فنی فقط عملیات زیرساخت |

## کارت اصلی «مطالعه زمان» در صفحه ۱۶
`حالت فرایند / خانواده / محصول / استایل / Revision / عملیات / واحد / روش / پیکربندی نفر و ماشین / زمان ثبت‌شده / تعداد نمونه / پراکندگی / وضعیت کنترل / تاییدکننده / اثر بازنگری`.
Tabs: `تعریف مطالعه`, `مشاهدات خام`, `تحلیل آماری`, `زمان پیشنهادی`, `تأیید و تاریخچه`.
Actionها: Start study, add observation, flag anomaly, calculate candidate, request review, approve, publish, invalidate; هرکدام با permission و audit.

## کارت ظرفیت صفحه ۳۲
- نوار بازه و سناریو: «مصوب»، «پیشنهادی»، «بدون زمان معتبر»، `SnapshotAt` و `DataAge`.
- ۴ KPI: person-min load/available، machine-min load/available، ظرفیت تحویل متناسب WIP، تأخیر متوقع.
- جدول محدودیت: Machine, Skill, Tool, Material, QA, Calendar; منبع شواهد و پیشنهاد قابل‌برگشت.
- اثر انتقال منبع بین خط مبدأ و مقصد در یک نما؛ دکمه تصویب تنها برای Planner.
- Download report با watermark وضعیت سناریو و hash داده ورودی.

## RTL و Responsive
- دسکتاپ: سایدبار سمت راست Hover/Pin؛ جدول عملیات با ستون‌های قابل انتخاب و نمودار Gantt.
- تبلت: پنل تفصیلی Collapsible؛ جدول قابل اسکرول **درون پنل** بدون overflow بدنه.
- موبایل: کارت عملیاتی به جای جدول عریض؛ شروع/توقف/ثبت خروجی در بالای صفحه ترمینال، فرم‌های کم‌مرحله؛ نمایش نفر-دقیقه و ماشین-دقیقه با Label صریح.
- اعداد فنی می‌توانند لاتین نمایش داده شوند اما `dir="ltr"` برای کد/Unit؛ UI فارسی راست‌به‌چپ. زمان شمسی کاربر و ذخیره UTC.
- صفحه بدون داده استاندارد، به‌جای صفر جعلی «هنوز زمان استاندارد تأییدشده ندارد» نمایش دهد.
