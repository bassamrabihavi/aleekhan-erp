# راهنمای فایل‌های CSV ثبت مطالعه زمان

- این فایل‌ها **قالب خالی** هستند؛ هیچ زمان استاندارد واقعی/مصوبی در آن‌ها نیست.
- `01_routes_REFERENCE_NOT_APPROVED.csv` شامل ۳۲ عملیات مرجع از چهار خانواده است؛ سطرهای کفش همگی پیشنهادی‌اند.
- برای جمع‌آوری مشاهدات فقط از `03_observations_BLANK.csv` یک نسخه جدید با شناسه/تاریخ مطالعه تهیه کنید؛ فایل اصلی را تغییر ندهید.
- فایل CSV با `UTF-8 BOM` ساخته شده تا فارسی در Excel به‌درستی دیده شود؛ تاریخ‌ها UTC/ISO 8601 و واحدها مطابق عنوان ستون‌ها هستند.
- هر فایل خام پس از ورود به سامانه باید Hash، شناسه واردکننده و مرحله Staging/Approval داشته باشد.
- هیچ فیلد دارای `std_...` تا قبل از تأیید رسمی مهندسی نباید مقدار پیش‌فرض خودکار بگیرد.
- CSV ابزار جمع‌آوری اولیه است و جایگزین دیتابیس رویدادمحور یا کنترل امنیت سازمانی نمی‌شود.
