# چطور خروجی Codex یا Claude Code را برای ممیزی به ChatGPT برگردانیم؟

۱. توسعه‌دهنده ابتدا **فقط** فاز یا Step مصوب را روی یک Git Repository خصوصی پیاده‌سازی می‌کند.
۲. پس از هر Step، گزارش Template و Commit/PR/diff و تست‌ها و Screenshot را در قالب پوشه `reports/phase-XX/step-Y/` و یک ZIP گزارش ارائه کند؛ هیچ اطلاعات حساس واقعی در گزارش ارسالی نباشد.
۳. کارفرما گزارش، فایل ZIP یا لینک مجاز Repository را به ChatGPT می‌دهد. این ارتباط **خودکار یا دائمی نیست** و ارسال توسط کارفرما/ابزار متصلِ مورد تأیید انجام می‌شود.
۴. ChatGPT با کد، تست و قرارداد مرجع مقایسه می‌کند؛ نتیجه `PASS`, `REWORK`, `BLOCKED` همراه شناسه ایرادات برمی‌گرداند.
۵. توسعه‌دهنده فقط اصلاحات را اعمال و گزارش جدید با commit جدید ارائه می‌کند؛ بعد از تأیید کارفرما مرحله بعد باز می‌شود.

### در گزارش باید دقیقاً چه چیزی باشد؟
- Branch + commit SHA و `git diff` خلاصه، Migration، مدل داده، API OpenAPI diff، screenshotهای UI، و فهرست تست‌هایی که واقعاً اجرا شده.
- برای هر تصمیم باز، Decision ID و شرط بلوکه شدن، بدون درج رمز/PII.
- برای سهولت، ضمیمه `REPORT.json` با schema موجود در `04_AGENT_WORKFLOW/REPORT_SCHEMA.json` هم تولید شود.

### چه چیزی به معنی تأیید نیست؟
- سبزبودن صرف CI بدون بررسی Permission و گواهی داده.
- خروجی mock/fake UI یا screenshot با backend غیرواقعی.
- ادعای Agent درباره «کامل بودن» بدون اثبات.
